Upload P&L exports (accrual basis). Add last month's workbook to split a YTD P&L into months. The tool validates each entity, calculates Gross / Net / EBITDA margins, and generates a colour-formatted, formula-driven Excel workbook.

05 — Combined Entity Analysis
ⓘ
Combined analysis. Tick two or more entities and click Add Combined Group. Revenue, Gross Profit, Net Income and EBITDA are summed first, then the combined percentages are calculated from those sums — percentages are never averaged. You can add as many groups as you need; each one becomes its own tab in the Excel workbook.
06 — Generate Workbook
Workbook tabs (same layout as the manual workbook): Consolidated Analysis (every entity + TOTAL), one tab per combined group, and one tab per entity (Jan… months + Total, raw P&L inputs in rows 4–10, calculated metrics in rows 14–20, QA checks and notes). Colour-coded: blue = typed-in source figures, black = formulas, light blue = latest-month formula, yellow rows = percentages, red = negatives. Every summary figure pulls from the entity tabs with formulas; percentages are calculated from summed dollars, never averaged.
